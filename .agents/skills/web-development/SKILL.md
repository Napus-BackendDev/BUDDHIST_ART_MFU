# Web Development and Coding Workflows

Use this skill when implementing UI components, CSS styling, backend APIs, and database models in BUDDHIST_ART_MFU.

## 🛠️ Tech Stack & Architecture Guidelines
* **Frontend**: Vue.js, Vuex Store, CoreUI components, Vanilla CSS.
* **Backend**: Node.js, Express, MongoDB (Mongoose schemas).
* **Database Models**: Refer to schemas under `backend/server/Project/*/models/*.model.js`.
* **State Management**: Modify actions and getters inside `frontend/src/store/modules/`.

## 🎨 Premium CSS Aesthetics Rules
1. **Design Principle**: Aesthetically superior UI. Wow the user on first glance.
2. **Color Palette**: Avoid simple default colors (red, blue, green). Use fine-tuned gradients or HSL/HEX variables.
3. **Interactive States**:
   * Always write hover and focus transitions in CSS:
     ```css
     transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
     ```
   * Apply subtle shadows, glassmorphism (`backdrop-filter: blur(10px)`), and thin borders for cards.
4. **Responsive Elements**: Use Flexbox, Grid, and media queries to support desktop, tablet, and mobile dimensions.

## 🚀 Token Efficiency Shorthand Rules
* **Diff Patches**: Present code changes in minimal diff format.
* **Targeted Inquiries**: Ask specific questions only when there is high ambiguity. Do not summarize approved plans.
